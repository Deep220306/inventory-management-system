# Inventory Management System

A full-stack Inventory Management System built using PHP, MySQL, HTML, CSS, and JavaScript.

## Features

* Product Management
* Supplier Management
* Sales Management
* Login Authentication
* Dashboard Interface
* CRUD Operations
* Search Functionality
* Dynamic Sales Tracking
* Session Protection

## Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* XAMPP

## Modules

### Product Module

* Add Products
* Edit Products
* Delete Products
* Search Products

### Supplier Module

* Add Suppliers
* Delete Suppliers
* Manage Supplier Records

### Sales Module

* Add Sales
* Track Sales History
* Update Product Quantity Automatically

## Database Tables

* products
* suppliers
* sales

## How to Run the Project

1. Install XAMPP
2. Start Apache and MySQL
3. Import the database into phpMyAdmin
4. Place the project folder inside `htdocs`
5. Open:
   http://localhost/inventory-management/products.php
